# HPC Requests

No HPC access is requested in this cycle.

The current work is correctness-bound, not compute-bound. A justified request requires:

1. a complete collector-motion environment and observation contract;
2. passing leakage, limiting-case, and matched-counterfactual audits;
3. validated scripted baselines;
4. a small pilot variance estimate;
5. an exact command, wall-time estimate, CPU/GPU/RAM requirement, storage estimate, and expected scientific decision.

Until then, Codex cloud is sufficient.
