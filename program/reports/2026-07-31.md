## Simple explanation

Imagine running the same world twice. The particles start in exactly the same places and receive exactly the same random bumps. In one world there is a weak common flow; in the other there is no flow. The collectors do not get told which world they are in. We ask whether the collectors touch their first particle earlier in the flow world.

For each matched pair, the score is the fraction of the episode saved:

`matched gain = (first-contact step in null − first-contact step in signal) / horizon`.

A positive number means the weak flow helped the fixed policy make contact earlier. The program will test a frozen grid of dimensionless signal strengths

`rho = alpha * sqrt(dt) / sigma`

and report the first grid point whose one-sided simultaneous 95% lower confidence bound is above zero. If the crossing lies outside the tested grid, the result will be reported as censored. The primary result will not pretend that a precise continuous “critical point” was measured.

The most important methods warning is random-number coherence. Merely giving signal and null runs the same PRNG seed is not enough if their control flow diverges and consumes randomness in a different order. The primary simulator therefore uses pre-generated Brownian noise and separated streams; event-keyed random draws remain a future robustness direction.

## Fresh AAMAS review

**Immutable review verdict:** reject  
**Overall score:** 2/10  
**Reviewer confidence:** 4/5

### Strongest accept argument

If fully implemented, this could become a useful controlled instrument: matched counterfactuals reduce nuisance variance; separating first contact from cascade growth prevents a lucky early capture from masquerading as sensing or coordination; and trajectory-level release could support reproducible multi-agent analysis.

### Strongest reject argument

The submitted package is presently a proposal, not a result. It lacks a complete environment, observations, policies, datasets, experiments, statistics, and empirical conclusions. More importantly for AAMAS, four collectors do not automatically create a multi-agent contribution. Without an experiment that matches collector count, swept area, information, actions, and policy capacity while changing only the coordination mechanism, reviewers can interpret the work as a single-agent particle-collection problem replicated four times.

### Mandatory repairs before a serious AAMAS claim

- stationary/passive-flux control;
- one collector;
- `M` independent collectors with no information exchange;
- the same policy class with and without a bounded shared summary;
- random, coverage, density-greedy, and local-flow scripts;
- centralized full-state oracle;
- area/perimeter-matched non-growing geometry;
- strict observation-leakage tests;
- fixed inferential protocol and seed budget;
- IPPO and MAPPO only after the scripted task-feasibility gate.

The full review is preserved verbatim in `paper/reviews/2026-07-31-fresh-aamas.md`.
