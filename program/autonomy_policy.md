# Autonomy Policy

## Safe without user input

- literature review using primary sources;
- reversible simulator and test implementation;
- scripted-baseline development and small Codex-cloud pilots;
- matched-pair diagnostics, data-schema validation, reproducibility work, manuscript scaffolding, reviews, and backlog maintenance;
- tested task-scoped commits to `research-autonomy`.

## User authority required

- credentials or secrets;
- paid/licensed data or new spending;
- major HPC allocation or VPN access;
- changing the single primary research question;
- adding a second active paper;
- final submission, authorship, or venue commitment.

Silence never blocks safe work. If one workstream is blocked, advance another. Never request passwords, tokens, or VPN secrets in chat.
